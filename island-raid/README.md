# 奪島遠征 Island Raid — 設計文件 & 原型

> Roguelike 戰略小隊遊戲。靈感來自 [Bad North](https://store.steampowered.com/app/688420/Bad_North_Jotunn_Edition/)，
> 但把核心反轉：**Bad North 是守島，我們是攻島。**

▶ 試玩：`/island-raid/`（純 HTML5 Canvas，無外部相依；`?auto` 參數可自動開局供測試）

---

## 一、核心概念

| | Bad North | 奪島遠征 |
|---|---|---|
| 立場 | 防守方：守住小島 | **進攻方：登陸奪島** |
| 失敗條件 | 房舍被燒光 | 小隊全滅（永久損失） |
| 勝利條件 | 擊退所有維京船 | **佔領全部據點 + 肅清守軍** |
| 節奏來源 | 一波波敵船進攻 | 灘頭選擇、據點攻堅順序、敵方援軍船 |
| Roguelike | 島鏈撤退路線、指揮官永死 | 島鏈進攻路線、小隊永死、戰利品構築 |

玩家扮演遠征軍指揮官，沿戰役航線逐島攻略：
**選灘頭搶灘 → 攻佔據點 → 肅清守軍 → 選戰利品 → 下一座島**，最終攻陷要塞。

## 二、單場戰鬥（一座島）

- 島嶼程序生成（值雜訊 + 放射衰減 + 高度平滑），有海灘、平原、高地、岩峰四種高度。
- 玩家小隊從**登陸艇**出發，點選灘頭搶灘——灘頭選擇本身就是戰術決策（近據點 vs 安全側翼）。
- 島上有 3–5 個**據點**（紅旗房舍）：小隊站上據點且周圍無敵軍即開始佔領（進度條），離開會慢慢流失。
- **守軍 AI**：平時駐防據點，玩家進入警戒圈或開始佔領時馳援；弓兵守距離放箭。
- 難度高的島會有**敵方援軍船**在固定時間登陸（進攻方也要打防守反擊）。
- 全據點易幟後殘餘守軍需肅清，敵援軍艦隊自動撤退。

## 三、兵種與技能

兵種（皆為小隊制，士兵個體演算）：

- ⚔️ **劍士**：均衡近戰主力
- 🏹 **弓兵**：遠程齊射、拋物線箭矢，近戰脆弱
- 🔱 **長槍兵**：重擊緩慢、正面堅實

技能（戰利品獲得、指派給單一小隊、冷卻制）：

- 💨 **衝鋒**：向目標方向猛衝並擊退敵兵——**推下海即溺斃**（致敬 Bad North 的招牌樂趣）
- ☄️ **箭雨**：區域傾瀉箭矢（限弓兵）
- 🛡️ **盾牆**：原地結陣，受傷 -65%（限近戰）
- 🚩 **集結**：治癒全隊並補充最多 3 名士兵

## 四、Roguelike 元素

- **戰役航線**：起始島 → 5 層每層 2 選 1（🏝️ 小島 / 💰 富庶島=兩件戰利品 / 💀 險惡島=更難但戰利品升級）→ 🏰 要塞。
- **戰利品構築**：每島擇一——援軍小隊 / 老兵勳章（晉升 ★，+傷害 +體力 +編制）/ 技能卷軸 / 軍旗（全軍 +1 編制）。
- **永久損失**：小隊全滅即從名冊移除；全軍覆沒 = 遠征失敗。
- **種子系統**：同種子同戰役，可分享挑戰；localStorage 記錄最佳紀錄。

## 五、操作

- 點小隊（或 `1`–`4`）選取 → 點灘頭登陸 / 點地面移動
- `Q` 或畫面下方按鈕發動技能；指向性技能進入瞄準模式後點目標
- 支援觸控（手機可玩）

## 六、技術備註與後續

- 原型為單檔 Canvas/JS（`game.js`），驗證玩法用；BFS 尋路、士兵個體戰鬥、偽 2.5D 高度渲染。
- 已用 CDP headless 整合測試：登陸、戰鬥、佔領、勝負、獎勵、戰役推進全流程。
- **後續移植 Godot**（主倉庫）方向：
  - 3D 小島 + 傾斜視角（貼近 Bad North 質感）
  - 音效 / 音樂、士兵動畫、擊退物理
  - 更多兵種（盾兵、火攻）、敵將、島嶼事件（濃霧、漲潮）
  - 指揮官特性（開局 perk）、meta 解鎖
